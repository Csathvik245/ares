## Draft disclosure (for the project page and the SI form field)

**Did we use SI tools? Yes.**

1. **Coding assistants.** The Ares Initiative used **Claude Code (Anthropic)** and **ChatGPT (OpenAI)** as coding assistants. They helped write and test code and documentation across the project: the route planner, the web app, the data-processing scripts, the unit tests, and the project docs (including this file, the README, the video script and the slides outline). Team members gave the instructions, reviewed the output, ran the tests and decided what to keep.
2. **Chat assistant for planning and review.** We used an AI chat assistant for brainstorming, planning, breaking the work into tasks, and reviewing our work.
3. **The ARES concept is ours.** The idea for ARES (a safe-return zone, oxygen budget and abort routes for an astronaut on foot at Jezero) is written up in our team's own design document. That document is the source for our shared rules and contracts in the repo (`CLAUDE.md`).
4. **No AI in route or safety decisions.** Every route, oxygen number, safe-return zone, abort route and GO / CAUTION / NO-GO status in the app comes from **deterministic algorithms**: Dijkstra and A\* search on a terrain grid, with fixed formulas and constants documented in [`assumptions.md`](assumptions.md). No machine-learning model or AI service makes or changes these decisions. The same inputs always give the same answer, and the planner has unit tests.
5. **Data is NASA's, not AI-generated.** The terrain, thermal and mineral layers come from NASA and USGS datasets listed in [`sources.md`](sources.md). AI tools helped write the scripts that process this data; they did not create the data values.
6. **Media.** Our demo video is a screen recording of the app with captions and no voice. No images, video or audio in the submission were generated by AI. If that changes, AI-made images and video will carry a visible watermark, and AI audio will be acknowledged in its description and metadata.
7. **No NASA branding** (logos, flags, mission identifiers) was generated or modified with AI.
